# Data dictionary

Generated by `python -m healthdw run`. Statistics are computed on the full tables. The CSV copy in `outputs/tables/data_dictionary.csv` also lists every indicator column of `cdc_indicators` and an example value for each column.

## cdc_indicators

Wide panel: one row per location and reporting period, one column per indicator (overall population).

| column | sql_type | pct_missing | n_unique | description |
|---|---|---|---|---|
| location_abbr | TEXT | 0.0 | 55 | Two-letter state, territory or US code. |
| location_desc | TEXT | 0.0 | 55 | Location name. |
| year_start | INTEGER | 0.0 | 7 | First year of the reporting period. |
| year_end | INTEGER | 0.0 | 4 | Last year of the reporting period (equal to year_start for single-year estimates). |

Plus 109 indicator columns (REAL), one per row of `indicator_catalog`, named by lower-case question_id (for example `dia01` is diabetes among adults).
